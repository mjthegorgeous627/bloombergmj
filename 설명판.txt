■ 전체 그림 (한눈에)

  [SAP / Portal / 엑셀]  <--  자동화 코드(파이썬)  -->  [workbench 화면(브라우저)]

  - 파이썬 파일들이 SAP, Portal, 엑셀을 자동으로 조작합니다.
  - 결과는 workbench.db(저장소)에 쌓이고, 브라우저 화면(보드)에 표로 보입니다.
  - 사용자는 화면 보드에서 확인하고 버튼을 누릅니다.


■ 파일은 이렇게 나뉘어 있습니다 (2026-10 기준)

  파이썬 쪽 (뼈대는 이미 정리됨)
   - workbench_app.py : 서버 입구. 화면을 띄우고 요청을 받아 아래로 전달만 함
   - db.py            : 저장소(데이터베이스) 담당
   - excel_sync.py    : 배송장 엑셀 주고받기
   - items.py         : 오더/품목 정보 처리
   - sap_ops.py       : SAP 작업
   - portal_ops.py    : Portal 작업
   - portal_*.py      : Portal 세부 단계(시리얼 등록, 포장, 라벨 등)

  화면 쪽 (지금 정리 중)
   - templates/dashboard.html : 화면 전부가 3천 줄 한 파일  ← 문제
     -> 주제별 8개로 나누는 중 (아래 참고)

  보관함
   - archive/ : 안 쓰는 진단·테스트 스크립트, 백업, 스크린샷을 모아둔 곳
                (지운 게 아니라 옮겨둔 것. 필요하면 꺼내 쓰면 됨)


■ 화면 파일을 나누는 이유

  한 서랍에 모든 물건이 섞여 있어서, 하나 고치다 다른 게 고장 나기 쉬움.
  실제 사고: 8/27 순서가 틀려서 화면 전체가 백지가 됨.
  -> 주제별 서랍으로 나누고, 읽는 순서를 고정해서 같은 사고를 막음.


■ 나누는 8개 주제 (화면 쪽)

  1. 기본 설정        화면 전체가 같이 쓰는 값. 항상 맨 먼저 읽힘
  2. 서버에 저장      변경 내용을 서버에 저장하는 함수들
  3. 표 그리기        보드의 행과 칸을 그리는 부분 (가장 큼)
  4. 실행 버튼        SAP/Portal/POD/ZREC 등 업무 자동화 버튼
  5. 행 편집          병합, 복사, 삭제, 메모행, 마감, 엑셀, 인쇄
  6. 드래그앤드롭      행을 끌어서 날짜/순서 이동
  7. 휴지통·달력       삭제 복원, 달력, 되돌리기
  8. 시작 코드        화면 켜질 때 한 번 실행. 항상 맨 마지막에 읽힘

  "OO가 이상하다" -> 해당 주제 파일만 열어보면 됨.


■ 안전 규칙

  - 한 번에 한 파일씩 옮기고, 옮길 때마다 화면이 정상인지 확인
  - 원본은 archive/backups/ 에 보관 (언제든 되돌리기 가능)
  - 기능은 바꾸지 않음. 사용자가 보기에 달라진 게 없어야 정상


■ 배송장 엑셀은 이제 파일 하나입니다 (2026-10-08 변경)

  C:\1\배송장\2026 배송장.xlsx   <- 이것 하나만 씁니다

  - 마감 버튼 : 이 파일에 오늘 날짜 시트(예: 10-8)로 저장합니다.
                저장이 실패하면 "마감 실패"로 뜨고, 보드 항목은 지워지지 않습니다.
  - Dashboard / 이력 검색 / 퀵 금액 정리 : 모두 이 파일을 읽습니다.
  - 예전의 "마감 파일"(backup\2026 배송장_마감.xlsx)은 더 이상 쓰지 않습니다.
    (두 파일이 사람 수정 때문에 계속 달라져서 하나로 합침)
  - 색 규칙 : 완료=파랑, 취소=회색, billed=초록. 새 날짜 시트는 날짜 순서 자리에 생깁니다.

     맞는 값 하나만 남기면 됨.

  5. 2027년 되기 전 : 파일 경로가 2026으로 박혀 있음 (config.py, 퀵 금액 정리 저장소).
  6. 그대로 두는 것 : 8월 18~24일 시트의 이월 행은 참고용이라 손대지 않음.
  7. 보류 중인 큰 작업 : 화면 파일 8개로 나누기, 왼쪽 메뉴 재설계.
