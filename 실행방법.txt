=============================================
  SAP 실행 방법
=============================================



─────────────────────────────────────────
■ 아침 시작 (모든 창 끄고 새로 시작)
─────────────────────────────────────────

PowerShell 열고 아래 명령어만 실행:

   cd C:\Users\bloomberg\Documents\MJSuh\mjbg\sap_automation

   python startup.py

   → SAP 자동 실행 + 로그인
   → 세션 4개 자동 설정 (VL06O / VL10G / ZRMA RLKR / ZRMA Q2)
   → Excel 자동 열기
   → 누락 오더 catchup
   → 20분 자동 반복

   ※ SAP / Excel 수동으로 미리 열 필요 없음
   ※  python main.py 는 SAP가 이미 켜진 상태일 때만 사용


─────────────────────────────────────────
■ 한눈에 요약
─────────────────────────────────────────

cd C:\Users\bloomberg\Documents\MJSuh\mjbg\sap_automation

  [ 아침 출근 ]
  python startup.py 실행 → SAP 오더 자동 수집 + Excel 기록 + 카카오톡 자동 전송

   [창 이미 켜져있는 상태에서는 ]
   python main.py 실행 → SAP 오더 자동 수집 + Excel 기록 + 카카오톡 자동 전송

   [카카오톡]
   따로 할 거 없음. main.py 켜두면 오더 들어올 때마다 자동으로
   내 카카오톡 "나에게 보내기"로 전송됨.

   [프린트 - Excel]
   python main.py --print-afternoon  → 오후 묶음 인쇄
   python main.py --print-tomorrow   → 내일 묶음 인쇄

   [Zebra 라벨 출력]
   python print_zpl_file.py                      → Downloads 최신 ZPL 자동 출력
   python portal_handler.py --order 9123456789   → 오더번호로 포털에서 직접 받아서 출력
   python print_nlbl.py kb [매수]    → KB Spare 용지 출력
   python print_nlbl.py kb5 [매수]   → KB5 Spare 용지 출력

   [퀵 배송]
   python main.py --quick [오더번호]  → 퀵.docx 작성 후 흑백 1매 출력
   예시: python main.py --quick 7780226
         (주소/회사명 자동 검색 → 터미널에서 확인/수정 후 출력)



─────────────────────────────────────────
■ 수동으로 즉시 실행 (main.py 돌아가는 중)
─────────────────────────────────────────

   새 PowerShell 창에서:

   cd C:\Users\bloomberg\Documents\MJSuh\mjbg\sap_automation

   python now.py      → 전체 4개 세션 실행
   python now.py 0    → 세션0 VL06O만
   python now.py 1    → 세션1 VL10G만
   python now.py 2    → 세션2 ZRMA_Q RLKR만
   python now.py 3    → 세션3 ZRMA_Q Q2만

   ※ 점심시간(11:20~13:20)에도 수동 실행은 가능


─────────────────────────────────────────
■ 프린트 (Excel → Samsung 프린터)
─────────────────────────────────────────

   새 PowerShell 창에서:

   cd C:\Users\bloomberg\Documents\MJSuh\mjbg\sap_automation

   python main.py --print-afternoon   → 오늘 오후 묶음 인쇄 (오늘 날짜 2번째 섹션)
   python main.py --print-tomorrow    → 내일 묶음 인쇄

   ※ 프린터: Samsung C56x Series, 가로 A4, 흑백, 2매
   ※ --print-tomorrow: 오늘 시트에 내일 날짜 섹션 없으면 내일 시트(예: 3-20)에서 자동 탐색


─────────────────────────────────────────
■ Zebra 라벨 출력 (Bloomberg 배송 라벨)
─────────────────────────────────────────

   새 PowerShell 창에서:

   cd C:\Users\bloomberg\Documents\MJSuh\mjbg\sap_automation

   【방법 1】 파일 직접 — 포털에서 이미 다운로드한 경우
   ─────────────────────────────────────
   python print_zpl_file.py
      → Downloads 폴더 최신 .ZPL 파일 자동 선택해서 출력

   python print_zpl_file.py "C:\Users\bloomberg\Downloads\SHIPLABEL_1 - 2026-03-23T140743.617.ZPL"
      → 경로 직접 지정해서 출력

   【방법 2】 오더번호 지정 — 포털 자동 접속해서 라벨 받아 출력
   ─────────────────────────────────────
   python portal_handler.py --order 9123456789
      → 해당 배송번호 페이지 접속 → 라벨 다운로드 → Zebra 출력

   python portal_handler.py --order 9123456789 --force
      → 이미 출력했던 번호도 강제 재출력

   ※ 포털 로그인 세션 자동 재사용 (portal_session.json)
   ※ 세션 만료 시 브라우저 창에서 로그인 후 Enter 누르면 계속 진행
   ※ 출력 이력: portal_printed.json (중복 방지)

   【방법 3】 KB Spare / KB5 Spare 용지 출력
   ─────────────────────────────────────
   python print_nlbl.py kb         → KB Spare 1매 출력
   python print_nlbl.py kb 3       → KB Spare 3매 출력
   python print_nlbl.py kb5        → KB5 Spare 1매 출력
   python print_nlbl.py kb5 2      → KB5 Spare 2매 출력

   ※ ZebraDesigner가 이미 열려있어도 동작 (새 인스턴스 불필요)
   ※ 창이 최소화된 채 실행 → 출력 완료 후 자동 닫힘


─────────────────────────────────────────
■ 카카오톡 자동 전송 (나에게 보내기)
─────────────────────────────────────────

   ※ 별도 명령어 없음 — python main.py 실행 중 새 오더가 Excel에 기록될 때 자동 전송
   ※ PC 카카오톡 앱 안 켜도 됨. 비용 없음.
   ※ 전송 후 J열에 "카톡 ✓ 26.03.19 14:32" 자동 기록됨
   ※ 프린트 범위(A~H)에 J열 포함 안 됨

   전송 형식 예시:
     [키보드 교체]
     배송 키보드5 10063421
     회수 일반키보드 10045196
     CHULMIN KANG / 02-2004-9908
     SHINYOUNG SECURITIES CO LTD 34-8 YOIDO-DONG
